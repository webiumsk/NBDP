# Concrete N02/N03/N16 inert bridge and binding freeze

**INERT_SOURCE_DATA_FREEZE / NOT_RUNTIME_READY; no execution authority.**
This adds closed data grammar to the accepted proposal and the five-file design.
It does not implement an interpreter, controller, helper, verifier or experiment.
All target/project/native/crypto/admission/control/network/container/browser work
still requires separate assignments and evidence gates. Accepted I4 is unchanged.

## Schema files and expected-data boundary

`bridge-schemas.json` is the full checker-side schema source. `definitions` and
`entrySchemas` define runtime data shape; `checkerOnlyDefinitions`,
`checkerEntrySchemas`, `checkerNativeSelection` and `bindingCatalogue` belong
exclusively to an independent future checker. Four `exactNative_*` definitions
use `literal` for the entire native13-key value: N02 JS/Rust source candidates
and N16 JS/Rust unchanged accepted paired expected objects. They are not prefix,
selected-field, substring or success-token expectations. Actual raw bytes and
same-context authentication joins remain mandatory beyond literal equality.

`worker-schemas.json` is a deterministic separately pinned projection, created
now for independent review. Its keys are exactly the full schema's common worker
keys: schema/state/runtimeReadiness/executionReleased/normativeAdoption/lane,
grammarDialect/grammarSemantics/byteRules/entrySchemas/definitions,
selectedCellNativeShapes/shapeOnlyNotice/ownership. Change only the schema label
to `e06-n02316-worker-schema-v1` and grammarSemantics.@name to the worker-only
namespace notice. All definitions, worker entrySchemas, structural native
selection and other common values are typed-identical. Remove every checker-only
definition/binding, exact native value and native-oracle source/selection pointer.
The full schema pins this projection; the projection has no reverse descriptor
that would create a hash cycle.

Future workers receive only the projected schema, exact worker data and admitted
runtime frame/manifest/release. Full schema, whole oracles, native candidates,
paired expected objects and expected originals are never worker inputs or parsed
worker data. Opaque source-closure integrity hashing does not turn checker files
into worker input. No worker branch may load the full schema and merely ignore
its checker section. Worker-native structural definitions are generated from
complete nested types/keys/tuple arities/null branches with generic bounded
scalar types; they contain no expected native canonical IDs, rumor content or
plaintext outputs. Known scope/schema/operation constants are ordinary protocol
checks, not injected native results.

All `@name` references resolve in definitions; only the independent checker may
add checkerOnlyDefinitions to that namespace. CLOSED-TYPED-RECORD-v1 has exact
mandatory keys/types, tuple arity and deep typed `literal` semantics. Object key
order is irrelevant; extra/missing keys and coercion refuse. No schema/data text
is executable, and no general expression or evaluation language exists here.

## Source-fixed checker binding catalogue

Only checker expected data may contain the one-key record `{bind:NAME}`. NAME is
one of the twelve fixed values below; there are no parameters, property paths,
expressions, functions, user-defined names or caller-provided binding dictionary.
Implicit context is the admitted exact cell and currently selected step. Values
come from the independently reconstructed raw/owned artifact graph. A binding
cannot resolve to null: expected absence is literal null. Missing, foreign,
ambiguous, not-yet-observed or unknown data refuses qualification.

| NAME | Resolved type and exact source |
| --- | --- |
| RECEIVED_D | Descriptor of this case's actual owned D receive record; unavailable in N02. |
| RECEIVED_F | Descriptor of this case's actual owned F receive record; unavailable in N03. |
| NATIVE_CALL | Descriptor of this case's unchanged ordinal0 native response record; unavailable in N03. |
| LOCAL_POLICY | Descriptor of same-case N16-S02 local DENY record, valid from S02 onward only. |
| SEAL_REFUSAL | Descriptor of same-case N16-S03 observed policy-refusal record, valid from S03 onward only. |
| WIRE_D_RECEIPT | Descriptor of actual D wire child's natural qualified terminal receipt from its own receive graph; unavailable in N02. |
| WIRE_F_RECEIPT | Descriptor of actual F wire child's natural qualified terminal receipt from its own receive graph; unavailable in N03. |
| NATIVE_TERMINAL | Descriptor of actual same one-request native child terminal receipt; only final N02/N16 step, never N03. |
| TERMINAL_RECORD | Descriptor of this case's qualified closed13-key no-seal terminal sidecar; only terminal/case reply context. |
| CASE_PID | Actual positive namespace-local process PID observed in the same case/parent graph; no predicted PID or tool-host/outer-host inference. |
| STEP_RECORDS | Array of actual owned scheduled whole-step descriptors, exact selected length2 or4 and source order; every step independently whole-checked before binding. |
| FINAL_STEP_RECORD | Descriptor equal to last member of STEP_RECORDS, binding the exact selected final step and terminal graph. |

Receive/native/policy/refusal descriptor identities remain unchanged across later
steps. Wire receipts remain the original wire terminal facts. The source catalogue

binding resolution still must verify descriptor bytes/hash/current ownership and
every schema/identity/raw span/native/stream/source/cleanup edge described here.

## Failure custody, limits and remaining gates

Qualified terminal requires natural exit0/reap/both EOF/unforced/empty stderr,
one consumed native reply/no extra output where applicable, all wire children
terminal, actual same-case no-call entry evidence and current integrity. N03
metadata lifecycle is NOT_STARTED, with no fabricated spawn/terminal receipt.
No-call counters are zero only where verified non-entry and current source/owned
resource evidence support zero. Attempted/unobserved work stays null; earlier
measured work is never reset to expected zero. Raw unexpected side effects or
nonconforming objects remain retained unqualified evidence, never repaired to fit
the qualified observation schema or whole oracle.

The earliest primary error and observed failure boundary remain intact; cleanup/
capture failures are bounded separate diagnostics. Later steps remain
NOT_EXECUTED/EARLIER_FAILURE. A schema failure, generic nonzero exit, substring,
unknown lifecycle, extra output, forced close or expired budget cannot become an
expected qualified negative. Public original remains null and no receipt or
business effect is authorized. This is not native-wide RC negative qualification.

Profile's finite 1500s phase includes setup; 240s windows retain rehash overhead.
Keep 20s wire,15s native-start,15s combined write/reply,5s native close, bounded
owned/window/final cleanup and original non-rebased parent monitoring. Raw data
parser remains32MiB; large binaries/source evidence use the protected streaming
hash/inventory path with original expected pins and finite file/byte caps. Never
feed opaque executable bytes into a raw JSON/data parser just to hash them.
The exact six-variable environment has no inherited proxy/credentials/Chrome
setting. The :18443 URL is metadata scope only: no TLS materialization, current
certificate validity, listener, acquisition client, consumer or browser is needed.
Historical positive TLS/source files remain byte-protected evidence.

Source/data freeze plus independent review precedes a separately bounded source

All19 LAB-N obligations,14 RC rows with native11 NOT_EXECUTED/3 NOT_READY/null,
