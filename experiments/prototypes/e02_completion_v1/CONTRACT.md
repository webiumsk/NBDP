## Phases, authority and actual lifecycle

All runtime commands require an externally hash-bound exact config and separate
root release for their phase. Release bytes are a coordinator trust input;
self-labelled JSON does not authenticate a real instruction or review. Root must
verify actual tool/agent correspondence externally, preserve original responses
immediately, and run the exact fixed foreground `/usr/bin/timeout --signal=TERM
--kill-after=3s 1800s` command. This uses the existing installed pinned timeout,
not a new process-monitor framework. Its nonzero/timeout outcome never qualifies.
Primary Rust RPC has the original source echo/stdin-close behavior, no new
per-RPC deadline or invented wait/EOF attestation. Actual natural outer exit0
and original tool receipts are mandatory before composition. The timeout bounds
owned Node/Rust descendants in their inherited process group; it starts no relay
or unowned process and is not a portable containment proof.

1. `primary` runs only the original execute function, preserves raw PARTIAL report,
   wires and source snapshots plus the real argv/release/interval in a subject.
2. `candidate` requires that actual primary subject and original outer API receipt
   witness, current consumer-v2 source/control acceptance, and executes the real

   spawnSync stdout/stderr/status/signal/error/argv/interval are preserved; no
   unavailable Popen EOF/reap fields are fabricated. It produces
   READY_FOR_INDEPENDENT_COMPLETION_REVIEW, never PASS.
3. `finalize` requires actual QA and security in two independent sessions on the
   exact candidate. It rechecks primary/source/control pins and reruns the DATA
   consumer, preserving a second explicit invocation rather than claiming cached
   data is a new run. This is DATA reinspection, not repeated Android/crypto or
   a new primary experiment. Only then may the separate external result be PASS.

PASS is scoped `EXTERNAL_RECONCILED_E02_CRITERIA_ONLY_NOT_STOCK_GATE_UPDATE`.
The raw primary report/skip remain intact; `canonicalRecordsChanged:false` and
