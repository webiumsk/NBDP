# NBDP Protocol Review

1. Read the relevant RFC and ADR.
2. Identify normative requirements.
3. Compare changes with existing NIPs.
4. Verify backward compatibility.
5. Review security and privacy implications.
6. Identify ambiguous protocol behavior.
7. Check independent implementation feasibility.
8. Propose positive and negative test vectors.

Return:
- Critical findings
- Architecture conflicts
- Missing test vectors
- Required decisions
- Approval recommendation
