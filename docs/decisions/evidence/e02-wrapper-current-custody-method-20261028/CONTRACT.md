# Proposed typed current custody for the E02 primary wrapper

Status: architecture proposal only. Root adoption and independent security review are required before a versioned wrapper implementation. No runtime, model result, grant, canonical gate promotion or protocol change is authorized by this document.

The current wrapper recursively interprets every exact-shaped descriptor found in every `.json` file as another host dependency. This admits no typed distinction between a current executable operand, an Android/container path, a preserved historical reference and an unmaterialized template. The accepted consumer source contains all of these. Its existing strict typed verifiers remain valid; generic recursive discovery cannot replace them. The retained findings give exact pins and JSON selectors for five failure classes.

## Authority and generation

The new wrapper CODE subject must pin a closed selector registry. Neither the runtime plan nor a caller can add selector expressions, replace a required root, designate an arbitrary file as an opaque exemption, or supply its own expected input list. Root separately reviews and pins the final current completion profile/source, producer source, consumer source, accepted control records, tools, native/E01, relay configuration and canonical protected artifacts.

Generation starts from these exact typed roots. It follows only the registry's explicitly named fields and arrays. Each parsed authority record has a closed key set, literal schema/version, expected role and exact current cross-reference joins. The registry contains no generic recursive-dictionary discovery and no suffix-based JSON interpretation. Unknown required authority schemas, extra operational fields, missing selectors, malformed pins and substitution of a different current root reject admission. Raw leaves are allowed only as the predetermined output role of a particular registry selector.

The generator produces a canonical sorted list of closed `{path,bytes,sha256}` host descriptors and a separate edge ledger. Duplicate identical host descriptors are deduplicated; conflicting descriptors for one canonical path reject. Every required selected edge is retained in the ledger with root kind, selector and interpretation. Inventory files and their own descriptors remain external to avoid self-reference. Root/concrete/source/model reviews and actual runtime receipts are separately pinned deferred operands, as in the existing release sequence.

## Raw bytes, parsed metadata and path domains

A selected raw host leaf is a canonical absolute regular file with no symlink component. The wrapper opens it with nonblocking/no-follow protection after an lstat/type check, checks owned handle identity, streams its SHA256 in bounded chunks and verifies byte count and pre/post identity. The raw payload ceiling is the existing8GiB selected-payload contract. It is not permission to allocate8GiB or increase the16MiB parsed metadata limit. FIFO/device/socket/directory/symlink or changed identity reject before a blocking read. SDK and dependency leaves do not become parsed records because their filename ends in `.json`.

Parsed authority JSON remains at most16MiB, strict UTF-8, duplicate-key/nonfinite/negative-zero rejecting and bounded in depth/nodes according to the current typed parser. No parser cap, protocol byte bound or strict consumer Files bound is widened. Preserve exact integer nanoseconds where required; fractional values are allowed only on already specified API duration fields. A26MB raw inventory stays exact hash-bound without entering this parser.

A guest/container descriptor is never opened at its embedded path on the host. Its reviewed typed mapping must identify an actual selected host descriptor and preserve the existing equality and containment assertions. An unmapped current runtime operand rejects; a historical mapping is retained as context and cannot satisfy a current mapping. NULL template descriptors remain template bytes and cannot supply a current operational selector.

## Authorship and independence

Replace `source_participants` blind recursive traversal with the same registry's typed participant edges. Each current SOURCE/DATA subject declares actual `authors[]` and `operators[]`. The forbidden union includes wrapper/completion/producer/consumer authors, current model/capture authors/operators, root, both actual windows, all retained failed attempts and historical contexts required by the existing whole-history verifier. Independent review records are review edges, not implementation authors. The whole consumer must return or produce an exact participant manifest whose typed derivation is verified; a caller-supplied unproved participant list is insufficient. Any unknown participant schema/required field or missing author/operator rejects.

## Timing, custody and final gates

Freeze CODE, selector registry, final profile, current model DATA and concrete review inputs before runtime release. The runtime plan binds completion source/profile; the profile binds immutable wrapper CODE only. No CODE/profile-to-runtime-plan cycle, no grant renewal and no old grant reuse. Preserve child240+3, root lease600, setup120, cleanup90, remaining-child243, actual same-T0 intent before observations, strict phase completion and owned-resource cleanup. The ordinary-client1800 gates are unchanged.

Measure the entire required selected input set before and after the actual scope; compare bytes, membership, modes, UID/GID and appropriate identity. The inventory is selected current custody, not a claim about the entire workspace or a race-free global snapshot. Preserve true outer Python API and inner regular-file semantics; no Node API, inner PID/reap or pipe EOF is fabricated. Timeout, missing input, drift, ambiguous custody, incomplete consumer data, cleanup failure or any unresolved required gate remains unqualified.
