## Findings and reproduction

### MEDIUM — mandatory E02 result integration is still absent

`experiments/e02-validation/test.mjs` unconditionally calls `ev.skip('Amethyst ordinary-client rendering', ..., true)` after saving its wires. The unchanged launcher therefore remains PARTIAL even if an external Android control later succeeds. Reproduction is source inspection of that final call and `Evidence.finish()` in `experiments/shared/evidence.mjs`; no experiment was run.

Required completion: independently reviewed, exact-pin Amethyst observations plus raw content/tag retention evidence and explicit result reconciliation. Either consume a qualified supplemental control record in a narrowly reviewed harness revision, or adopt a reviewed versioned reconciliation record while retaining the original JSON/history. Merely deleting the skip or manually assigning PASS is insufficient. A changed harness requires fresh applicable provenance and review. Ordinary chat need not understand an NBDP business envelope; harmless JSON display or unsupported business UI is not by itself NBDP conformance failure.

### MEDIUM — legacy E06 still takes some consumer authority from producer fixtures

`experiments/e06-kind15/test.mjs:19–20` retains the validated received file rumor but not the received envelope as consumer authority. Line 27 assigns `bytes: e.document.bytes` from the producer-side fixture; line 28 checks against fixture `e.document.sha256` and uses fixture mirror URL `urls[1]`. URL/key/nonce/x/ox partly come from the received file, but complete profile/size/envelope commitment authority is not exclusively derived from received validated state. This is a source-level coverage defect against the current user criteria, **not an observed runtime vulnerability**; canonical E06 has not executed.

Required completion: retain authenticated received envelope and file, derive selected suite/profile, plaintext/ciphertext sizes and commitments from that pair, and keep the original vector only as the independent checker oracle. Fallback locations must have explicit validated-message or separately declared trusted-policy provenance. Add actual received-path wrong-size/hash/unsupported-profile cases, preserving no-effect assertions. Newer composed prototypes may already implement stronger rules; do not transfer their acceptance to this unchanged legacy harness.

### MEDIUM — previously confirmed target policy marker defect remains open

[Existing finding](../invoice-authenticated-carrier/e06-https-acquisition-preparation-r1/negative-target-policy-marker-finding-r1.json): `e06_relay_https_negative_v1/protocol.mjs:309` requires an absent contiguous `ADOPTED_TECHNICAL_POLICY=transport-sub-evidence-v1` string. The exact pinned adopted document contains the two markers separately; Python checks them separately. Static inspection predicts a legitimate target refusal before target side effects; no target runtime observed it.

Required completion: narrow source correction, preserved policy pin and all dependency checks, independent review of the new complete closure, genuine new source/control evidence joins, then actual positive/negative marker/pin regressions before TARGET release. Existing 14-row capture embeds the old complete closure and cannot be relabeled. Fixing this before LOCAL/native qualification avoids qualifying observations against a known soon-obsolete source.

### LOW — current indexes omit later scoped work or present historical state without a clear current layer

The 2026-10-11 validation summary's canonical table is accurate for its preserved records, but its statements that frame budgets are wholly unmeasured / kind 15 is wholly untested require a current dated layer linking the later partial acceptances. The immutable adopted policy's initial “No candidate currently satisfies” statement is superseded in bounded scopes by later qualifications; preserve its pinned bytes and add a current index rather than silently mutating that authority document. PR/branch truth needs the coordinator's live GitHub check; this audit makes no unverified PR-state claim.
